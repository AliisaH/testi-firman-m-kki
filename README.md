# Solo Business Hub – Käyttöjärjestelmä Yksinyrittäjälle (Demo)

Tekoälyavusteinen "All-in-One" -työtila ja käyttöjärjestelmä (Business OS) asiantuntijapalveluita tarjoaville yksinyrittäjille. Tämä on kevyt, selaimessa toimiva käyttöliittymäprototyyppi, joka yhdistää suunnittelun, myynnin, projektinhallinnan ja talouden periaatteella: 

*PLAN → DECIDE → DO → SCHEDULE → SELL → DELIVER → INVOICE → RECEIVE CASH → REVIEW → IMPROVE.*

## 🚀 Ominaisuudet

*   **Today Dashboard:** Operatiivinen ohjaamo, joka kokoaa päivän tapaamiset, tärkeimmät tehtävät ja kassavirtatilanteen yhdelle näytölle.
*   **CRM ja Myyntiputki:** Keksittyyn synteettiseen dataan perustuva myyntimahdollisuuksien ja asiakkuuksien hallinta.
*   **Talous ja Kassavirta:** Visuaalinen katsaus rullaavaan 12 kuukauden kassavirtaan, laskutustavoitteisiin ja varauksiin (ALV, YEL).
*   **Tekoälyagentit (Simulaatio):** Valmiit näkymät tekoälyavustajille, kuten Finance Agent ja Sales Agent, jotka on suunniteltu analysoimaan taustadataa.

## 🛠 Teknologiat

Tämä projekti on toteutettu puhtaana frontend-demona ilman raskasta taustajärjestelmää tai erillistä tietokantaa:
*   **HTML5** (Yksisivuinen arkkitehtuuri)
*   **Tailwind CSS** (Responsiivinen, minimalistinen ja ammattimainen ulkoasu CDN:n kautta)
*   **Vanilla JavaScript** (Käyttöliittymän logiikka, navigaatio ja synteettisen datan renderöinti)
